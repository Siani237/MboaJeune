# Mboa Jeunes Créatifs — Dossier d'exécution

**Version :** 1.0  
**Périmètre :** site vitrine + Pool de talents + espace d'administration de démonstration  
**Cadre technique imposé :** Angular + Mock Backend (aucun backend réel à ce stade)

## Décisions de départ

- Construire une application Angular sur mesure.
- Utiliser des composants standalone, TypeScript strict, Angular Router et Reactive Forms.
- Séparer l'interface, la logique métier, les contrats de données et les dépôts de données.
- Implémenter des repositories simulés avec des données fictives.
- Prévoir le remplacement des repositories simulés par des repositories HTTP, sans réécrire les pages.
- Ne jamais utiliser ce Mock Backend pour recevoir ou conserver de véritables candidatures ou données personnelles.
- Ne pas présenter l'authentification simulée comme une protection de sécurité.
- Ne pas publier de collecte réelle ni diffuser le QR code de collecte tant que le backend, les contrôles serveur et les validations juridiques ne sont pas en place.

## État réel au démarrage

Le dossier fonctionnel a été fourni, mais aucun dépôt source Angular ni code existant n'a été joint à cette mission. Les documents ci-dessous constituent donc le cadrage d'exécution et les spécifications de réalisation. Ils ne prétendent pas qu'une application a déjà été codée, testée ou déployée.
